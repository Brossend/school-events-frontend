Реальные prototype reactions: `prototype-links.json`. Сохранить проект `1:1451` ведёт в `1:639`; экспорт `1:1307` ведёт в `82:456`; возврат из протокола `112:1537` ведёт в `1:1260`. У editing/saved/checklist экранов нет собственных reactions. Поэтому FE-007 реализует один `/scenarios/:id/edit` с локальными состояниями, полями и modal, а не отдельную Nuxt-страницу для каждого Figma frame. Read-only просмотр остаётся `/scenarios/:id`.

Отдельных макетов полной истории ревизий, optimistic-lock 409 и успешного действительного допуска в исследованных редакторских семействах не найдено. Добавлены компактный выбор известного номера ревизии, сравнение конфликта и сообщение фактического ответа сервера в существующем UI-kit. Они не выдаются за найденные Figma frames. Протокол Figma содержит демонстрационные категории и незаполненные фактические заключения; приложение выводит действительные findings, а не переносит демонстрационный успех.

Экспорт и связанные прототипные экраны исключены из реализации FE-007 по границам задания. На мобильных панель проверки перемещается после материала; формы и сообщения переносятся без горизонтального скролла. Скриншоты P0/P1 и конфликта через изолированный harness имеют видимую маркировку fixture; настоящие серверные P0/P1 дополнительно подтверждены HTTP evidence.
