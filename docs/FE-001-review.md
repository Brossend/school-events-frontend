## Найденные расхождения и ограничения

1. Remember-me отключён с пояснением: backend не поддерживает параметр. Это осознанное отличие от активного чекбокса макета.
2. Demo-кнопка открывает объяснение отсутствия backend-возможности вместо перехода в вымышленную сессию.
3. Восстановление показывает недоступность и путь через администратора школы; успешная отправка и confirmation-screen не имитируются.
4. Вход содержит дополнительное пояснение недоступного длительного входа. Focus/hover/reduced-motion добавлены как функциональные состояния доступности.
5. Точные самостоятельные макеты профиля пользователя, tenant selector и системного статуса не подтверждены; они собраны из исследованных токенов/layout. Профиль школы `1:497` оставлен на FE-011.
6. OpenAPI `/auth/me` расходится с фактическим AuthController. Адаптер и тест находятся во frontend; backend-спецификация требует отдельного согласования.
7. Backend health `localhost:8000` отклоняет подключение, Docker API недоступен. CORS, cookies и RBAC с реальными аккаунтами требуют интеграционной проверки после запуска существующего backend.
8. `npm audit` после обновления Nuxt/Vitest/happy-dom показывает **7 high** в транзитивной цепочке `node-forge → listhen → nitropack → Nuxt`. Опубликованный в используемом registry `node-forge@1.4.0` попадает под GHSA-86w9-cpqp-85rv; предложенный audit downgrade Nuxt не применялся. Полный результат — `npm-audit.json`. Релиз не заявляется прошедшим dependency security review; этот вопрос остаётся для независимой проверки.
