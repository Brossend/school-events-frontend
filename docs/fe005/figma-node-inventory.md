Перенесены пять индикаторов, нумерованные заголовки, основная белая форма и сводка «Ваш проект», зелёные выбранные карточки, история параметров при возврате и адаптивное складывание колонок. Использованы существующие Inter, UiField/UiTextarea/UiButton/UiAlert/UiCard/UiState/UiPagination, штатный layout и иконки. React/Tailwind reference не включён в runtime. Три PNG-референса в evidence — материалы проверки, не UI assets.

Контрактные отличия: нет принимаемых полей даты/площадки/региона/литеры/возрастной группы/командного распределения; они не имитируются. «Командная игра» не имеет format_type, поэтому предложен отдельный действительный формат «Круглый стол». API принимает одну value_direction. Ресурсы — реальные строки, предложения checkbox не выданы за серверный enum. Для собственного повода и традиции добавлены реальные переключатели источника, отсутствующие в демонстрационной заполненной форме. Штатная навигация FE-004 с пятью разделами сохранена.

Снимки реализации: evidence/step-{1..5}-{1440,768,390,360}.png. Contact sheet: evidence/responsive-contact-sheet.jpg. Сравнение выполнено визуально по композиции, цветам выбранных состояний, порядку и адаптивности; pixel-perfect идентичность не заявляется: изменены тексты под реальный контракт и отсутствует неподдерживаемая часть полей, сохранён ранее принятый shell.
